## 1. Glossary

| Term | Meaning |
|---|---|
| Track-guided | Fabric retained in side channels as it moves |
| Side spline | Edge strip that keeps fabric located in the side track |
| Central locking | Mechanism that holds the blind at a set height |
| Pelmet | Box at the top that houses the rolled blind |
| Bottom bar | Weighted rail along the lower edge |
| Skirt / weather strip | Seal along the bottom edge |
| Dog clip | Stainless steel clip securing the bottom of a crank or café blind |
| PVC | Clear or tinted transparent material |
| Mesh | Woven fabric that filters light and allows airflow |

## 2. Systems Overview

| System | Mechanism | Operation |
|---|---|---|

## 7. Weather Notes

- PVC shelters well from wind and rain but should not be treated as completely sealed in every storm.
- Track-guided systems are designed to stay stable in windy conditions.
- Follow the care guidance for strong winds.
